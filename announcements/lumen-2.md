# Lumen-2: Vision-Language Understanding for Real Documents

**Aurelite Labs — model announcement · 22 October 2025**

Lumen-2 is a 7.4B vision-language model that replaces Lumen-1. It adds document
understanding, chart reasoning and a new image-token compressor, and ships with a refreshed
model card and serving guide.

## Highlights

- 7.4B parameters, image + text input
- New image-token compressor (4x fewer visual tokens)
- Document, chart and table question answering
- Apache-2.0 weights and inference code

## Availability

- Model card and serving guide: `docs/lumen-2/README.md` in the press room
- Code and weights: `https://github.com/komal74784391-netizen/aurelite-code-lumen-2`
