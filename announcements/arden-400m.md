# Arden-400M: Compact Multilingual Coverage

**Aurelite Labs — model announcement · 3 November 2025**

Arden-400M is a 420M compact multilingual model covering 23 languages and aimed at
on-device deployment. It uses a shared vocabulary distilled from the Aurelite multilingual
corpus and a compact transformer backbone.

## Highlights

- 420M parameters
- 23 languages, shared subword vocabulary
- Fits in ~1.1 GB at 8-bit precision
- Accepted at NeurIPS 2025

## Availability

Arden-400M is a research artifact. The model card on this page is the only public artifact
for this release; no public code or weights are being published. Please contact the authors
for research collaboration requests.
