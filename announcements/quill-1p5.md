# Quill-1.5: A Code Assistant That Runs on a Laptop

**Aurelite Labs — model announcement · 5 November 2025**

Quill-1.5 is a 1.5B code-assistant model with a fill-in-the-middle objective and a
repository-aware context builder. It targets laptop-class inference and ships with an
editor integration example.

## Highlights

- 1.5B parameters, 16k context
- Fill-in-the-middle and repository-aware prompting
- Runs in ~3 GB at 8-bit precision
- Apache-2.0 weights and inference code
- Accepted at NeurIPS 2025

## Availability

Code and weights are published in the official code repository:
`https://github.com/komal74784391-netizen/aurelite-code-quill-1p5`
